# Security Notes

- Keep `data/raw/`, `data/processed/`, trained model binaries, and runtime alert logs out of Git.
- Run the FastAPI server on `127.0.0.1` for local development.
- Do not expose `/predict` or the Streamlit app publicly without a threat model and deployment
  controls (authentication, authorization, TLS, rate limiting, resource limits, monitoring).
- Only load model artifacts generated by a trusted local training process. Joblib files can
  execute code during deserialization; never load untrusted artifacts.
- Treat model output as a signal for investigation, not as a verified security incident.
- Report security concerns privately to the repository maintainer rather than publishing sensitive
  exploit details in an issue.
